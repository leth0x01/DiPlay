# LynkPlay Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task in the existing `lynkplay` branch.

**Goal:** 建立可与 DiPlay 共存的 LynkPlay 主应用品牌基线。

**Architecture:** 保留 namespace、内部类型、资源键和车型接口，只调整主应用身份、用户可见品牌、公开文件目录及更新来源。主应用更新跟随当前 fork。

**Tech Stack:** Android、Kotlin、Gradle、JUnit、Robolectric。

## Global Constraints

- 目标为 2023 款领克 06 燃油版 Android 9，实车适配待诊断验证。
- release applicationId 为 `com.leth0x01.lynkplay`；debug 后缀保留 `.hudtest`。
- 保留 `com.shilapi.xcertplay` namespace、持久化键、接口 action、上游许可证与来源说明。
- 不新增图标设计或设置布局，不改认证资源和签名配置。
- 完整执行 AGENTS.md 要求的检查；环境问题应报告实际结果。
