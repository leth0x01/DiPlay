## 实现

- iAP2 接收有效位置时记录 `positionUpdatedAtNanos`；即使位置数值相同，也按新上报校准。专辑、歌手等元数据补充保留已有时间基准。
- 播放时从已知位置外推，暂停时冻结；状态切换未带位置时保持连续。未知位置不外推，已知有效时长限制显示上界。
- 原车主动进度事务和 `IMusicClient` 进度查询使用同一计算方式。
- 原车媒体中心持有控制权、会话有效且处于播放状态时，每秒刷新进度。定时任务只发送进度，不重发歌曲或封面。
- 暂停、来源切换、失去控制权、断开和关闭后终止定时刷新；每次任务执行及发送后重新检查控制权和令牌。
- 标准媒体元数据比较忽略进度时间字段，避免仅更新时间就重复发布封面。
