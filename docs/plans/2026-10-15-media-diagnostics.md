# 媒体操作自动诊断实施计划

**目标：** 正常使用后导出的报告可关联原车媒体操作、实际 HID 发送、手机状态以及封面发布和读取，无需固定车测步骤。

**设计：** 只补充诊断，不改变指令、重试、播放状态和封面发布策略。媒体请求使用会话内编号和单调时间，手机状态只记录为观察结果，不冒充指令确认。封面使用文件编号关联，原车日志读取使用有限范围与后台生命周期。

1. 在 shared 增加有界媒体请求跟踪器及测试，覆盖多次请求、超时、已处于目标状态和关闭。
2. CarPlayController 记录提交、排队、发送与状态观察；AirPlaySession 返回按下/释放各自的发送结果。
3. 封面服务记录发布、每次读取、HTTP 状态、耗时和失败；媒体中心记录同一封面编号与歌曲版本。
4. 会话期间尝试只读采集原车 DIM/媒体日志并写入现有轮转日志；记录权限与进程退出情况。
5. 执行 AGENTS.md 指定的完整 CI 检查，整理实际验证结果。
