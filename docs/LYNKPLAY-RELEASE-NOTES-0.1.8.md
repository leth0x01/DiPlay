# LynkPlay 0.1.8

版本配置：`0.1.8` / versionCode 46；carTest 版本名称为 `0.1.8-lynk06-test`。上游基线：DiPlay 0.2.19（`9aa9c549`）。

## 本次同步

- 合并 DiPlay 0.2.19，保留 LynkPlay 安装标识、更新来源、领克车型门禁和仪表适配。
- CarPlay 三指下滑菜单使用上游玻璃面板布局，顶部固定标题与关闭按钮，底部固定“保存并重新连接”，退出应用位于滚动列表末尾。保留领克宽屏尺寸和窗口安全边距。
- 可从手机端下载诊断报告，通过 QR 码或地址与验证码访问；报告与车机本地导出使用同一生成逻辑。
- 同步上游 USB 启动、通话／Siri／导航语音播放时间、画面恢复及翻译更新。完整上游变更见 [DiPlay 0.2.19 版本说明](RELEASE-NOTES-0.2.19.md)。

## 当前实车状态

2026-10-13 用户反馈确认，2023 款领克 06 燃油版、Android 9 真实车机上的无线、有线 CarPlay 均能连接。声音出现异常，待排查。在该次反馈之后确认，仪表地图需要平台签名的车测包，实测步骤见[车测说明](LYNKPLAY-CAR-TEST.md)。

本次反馈未指定安装包版本，以上实车结果不作为 0.1.8 的完整验收结论。上游音频修复已合并，实际声音异常仍需结合车机诊断报告定位。

## 验证与后续测试

合并时的本地单元测试、Lint、Debug 构建及大字体菜单截图结果见 [LynkPlay 验证记录](LYNKPLAY-VALIDATION.md)。后续重点核对声音异常、仪表地图和连接稳定性，操作与诊断采集步骤见[车测说明](LYNKPLAY-CAR-TEST.md)。
